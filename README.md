# Sistema de tiendas y Centro de Distribución (Proyecto final SGI)

## Estructura
app.py, requirements.txt, config/conexion.py, modulos/*.py (igual que la guía 6).

## Puesta en marcha
1. Importar `base_datos_proyecto.sql` en phpMyAdmin (local) y luego en Clever Cloud.
2. Subir esta carpeta a GitHub (sin credenciales).
3. En Streamlit Community Cloud: New app > repositorio > rama main > app.py.
4. Pegar las credenciales en Secrets (ver secrets_ejemplo.toml).
